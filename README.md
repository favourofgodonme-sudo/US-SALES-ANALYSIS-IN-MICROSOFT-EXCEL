# US-SALES-ANALYSIS-IN-MICROSOFT-EXCEL
A data analyed into visuals to show the highest sales, profits, products sold highest, top 5 customers and more
I started with reviewing the data set, after which I defined the business problem 
And then I went into data cleaning and manipulation, after which I converted the data to a table before I started analysing the data and creating my visuals for better understanding of the data
At the end of the analysis, I was able to get the highest profit, customers and sales for each year which helped me to give my recommendations and solve the business problem 
my dataset was gotten from keggle.com.
